# Darktide Skills

AI is useful for automating tests and analyzing problems. Use it responsibly and supervise its work, especially in areas you don't know well. These skills don't replace your judgment. You are still responsible for checking the results.

## Installation

Install these skills using any method supported by your agent. For example, with the [Skills CLI](https://www.skills.sh/docs/cli) (requires Node.js):

```sh
npx skills add deluxghost/darktide-skills
```
