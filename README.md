# Darktide Skills

AI is useful for automating tests and analyzing problems. Use it responsibly and supervise its work, especially in areas you don't know well. These skills don't replace your judgment. You are still responsible for checking the results.

The skills are also designed to be readable by human, so you can read them as documentation.

## Installation

The simplest way is to ask your AI agent to install them, like:

```text
Install the skills from https://github.com/deluxghost/darktide-skills
```

To install them yourself, use any method supported by your agent. For example, with the [Skills CLI](https://www.skills.sh/docs/cli) (requires Node.js):

```sh
npx skills add deluxghost/darktide-skills
```

You can also copy the folders under `skills/` into your agent's skills directory.
